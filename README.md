# 동그라미 습관 앱

아이폰과 안드로이드 브라우저에서 사용할 수 있는 개인용 습관 체크 웹앱입니다.

## 포함 파일
- `index.html`: 앱 화면과 기능
- `manifest.webmanifest`: 홈 화면 설치 설정
- `sw.js`: 오프라인 캐시 설정
- `icon.svg`, `icon-192.png`, `icon-512.png`: 앱 아이콘

## GitHub Pages에 올리는 쉬운 방법
1. GitHub에서 만들어 둔 저장소를 엽니다.
2. **Add file → Upload files**를 선택합니다.
3. 이 폴더 안의 앱 파일 6개(`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`)를 선택해 업로드합니다. `README.md`도 함께 올려도 됩니다. `README.md`도 함께 올려도 됩니다.
4. 아래쪽 **Commit changes**를 눌러 저장합니다.
5. 저장소의 **Settings → Pages**로 이동합니다.
6. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
7. Branch는 `main`, 폴더는 `/(root)`로 선택하고 **Save**를 누릅니다.
8. 잠시 기다린 뒤 Pages 화면에 표시되는 주소를 엽니다.

저장소가 `username.github.io` 형식이 아니라면 주소는 보통 `https://사용자이름.github.io/저장소이름/` 형식입니다.

## 휴대폰 홈 화면에 추가
- **iPhone (Safari)**: 공유 버튼 → 홈 화면에 추가
- **Android (Chrome)**: 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치

## 기록과 백업
- 기록은 로그인이나 서버 없이 해당 브라우저의 로컬 저장소에 저장됩니다.
- 다른 기기/브라우저와 자동 동기화되지 않습니다.
- `백업` 버튼으로 JSON 파일을 저장하고, `복원` 버튼으로 불러올 수 있습니다.
- 브라우저 데이터 삭제, 앱/브라우저 변경, 기기 교체 전에는 백업을 권장합니다.

## 반복 일정 기준
- 격일: 습관을 처음 만든 날부터 하루 걸러 반복
- 주 1회/주 2회: 선택한 요일에 반복
- 주말만: 토요일과 일요일에 반복
- 달력의 격일 습관은 쉬는 날에 점이 표시되지 않습니다.
- 달성률은 이번 달 오늘까지 예정된 습관 체크 중 완료한 비율입니다.
- 연속 달성은 예정된 습관이 하나 이상 있는 날 중, 모든 예정 습관을 완료한 연속 날짜 수입니다. 예정 습관이 없는 날은 연속 기록을 끊지 않습니다.
